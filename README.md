# 직장인 텔레스트레이션 (그림 전화)

친구들과 비동기로 즐기는 직장인 텔레스트레이션(그림 전화) 웹 게임.

## 요구사항

- **Node.js 22.5 이상** (내장 `node:sqlite` 모듈 사용 — 별도 DB 설치/빌드 불필요). 배포 플랫폼에서 Node 버전을 지정할 수 있다면 24 이상을 권장(`.node-version` 파일 포함).

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000` 에서 접속.

## 환경변수

| 변수 | 용도 | 필수 여부 |
|---|---|---|
| `PORT` | 서버 포트 (기본 3000) | 선택 |
| `DATA_DIR` | SQLite DB 저장 경로 (배포 시 퍼시스턴트 볼륨 경로로 지정) | 선택 |
| `KAKAO_JS_KEY` | [Kakao Developers](https://developers.kakao.com)에서 발급받은 JavaScript 키. 설정하면 카카오톡 인앱 브라우저 안에서도 "다음 참여자 지정" 시 카카오톡 채팅방 선택 UI가 직접 뜸(없으면 기존처럼 클립보드 복사로 대체됨) | 선택 — 카카오톡 인앱 공유 기능을 쓰려면 필요 |

`KAKAO_JS_KEY`를 쓰려면 Kakao Developers에서 앱을 만들고 "플랫폼 > Web"에 실제 배포 도메인(및 로컬 테스트용 `http://localhost:3000`)을 등록해야 합니다.

## 게임 흐름

1. 홈에서 "새 게임 만들기" → 제시어 + 참여자 수(홀수, 본인 포함) 입력.
2. "다음 참여자 지정" 버튼으로 공유 링크 생성 → 카카오톡/인스타그램 등으로 전달.
3. 링크를 받은 사람은 접속 후 "시작"을 누르면 30초 동안 그림을 그리거나 제시어를 맞힘.
4. 마지막 참여자가 제출하면 게임 종료, 결과 캐로셀에서 전체 릴레이 확인.

## 알려진 한계

- 카카오톡/인스타그램 등 앱별 인앱 브라우저는 저장공간이 격리되어 있어, 같은 기기라도 다른 앱에서 열면 다른 사용자로 인식됩니다.
- 30초 제한은 서버가 직접 강제하며, 서버 프로세스가 재시작돼도 진행 중인 턴의 타이머를 복원합니다.
- 비속어 필터링, 로그인/인증 등은 포함되어 있지 않습니다(캐주얼한 친구 게임 용도).
- 인스타그램 인앱 브라우저는 카카오톡과 달리 이런 SDK가 공개되어 있지 않아, `KAKAO_JS_KEY`를 설정해도 인스타그램 안에서는 여전히 클립보드 복사 폴백에 의존합니다.
