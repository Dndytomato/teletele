# 텔레스트레이션 (그림 전화)

친구들과 비동기로 즐기는 텔레스트레이션(그림 전화) 웹 게임.

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000` 에서 접속.

## 게임 흐름

1. 홈에서 "새 게임 만들기" → 제시어 + 참여자 수(홀수, 본인 포함) 입력.
2. "다음 참여자 지정" 버튼으로 공유 링크 생성 → 카카오톡/인스타그램 등으로 전달.
3. 링크를 받은 사람은 접속 후 "시작"을 누르면 30초 동안 그림을 그리거나 제시어를 맞힘.
4. 마지막 참여자가 제출하면 게임 종료, 결과 캐로셀에서 전체 릴레이 확인.

## 알려진 한계

- 카카오톡/인스타그램 등 앱별 인앱 브라우저는 저장공간이 격리되어 있어, 같은 기기라도 다른 앱에서 열면 다른 사용자로 인식됩니다.
- 30초 제한은 서버가 직접 강제하며, 서버 프로세스가 재시작돼도 진행 중인 턴의 타이머를 복원합니다.
- 비속어 필터링, 로그인/인증 등은 포함되어 있지 않습니다(캐주얼한 친구 게임 용도).
